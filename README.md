*DESCRIPTION*: The Weather App (CLI) is a Python-based application developed as part of an internship task to understand the practical implementation of Python programming, API integration, and data handling. The main objective of this project is to create a simple command-line application that allows users to check the current weather conditions of any city by entering its name. The application retrieves real-time weather information from the OpenWeatherMap API and displays the results in a clear and user-friendly format.

Python is the primary programming language used to develop this application. The Requests library is used to send HTTP requests and retrieve weather information from the OpenWeatherMap API. Visual Studio Code is used as the development environment, while the Command-Line Interface (CLI) allows users to interact with the application through a terminal. The project requires an API key to access weather information from the external server.

The application follows a simple working process. First, the user runs the Python program and enters the name of a city. The program sends a request to the OpenWeatherMap API with the city name and API key. The API processes the request and returns weather information in JSON format. The Python program extracts the required details and displays them on the screen. These details include the city name, temperature in Celsius, feels-like temperature, humidity percentage, weather description, and wind speed. If the user enters an invalid city name or the application encounters a network problem, an appropriate error message is displayed. Exception handling is used to manage network-related errors and improve the reliability of the application.

The Weather App provides several useful features, including searching for weather conditions by city name, displaying current temperature and humidity, showing wind speed, and presenting general weather conditions. It also supports continuous searches, allowing users to check the weather of multiple cities without restarting the program. The application terminates when the user enters the exit command. These features make the program simple, interactive, and easy to use for beginners.

During the development of this project, practical knowledge of Python programming was improved. The task provided experience in using external libraries, connecting to web APIs, processing JSON data, handling exceptions, and implementing functions, loops, and conditional statements. It also helped develop logical thinking, debugging skills, and problem-solving abilities. Furthermore, the project demonstrated how programming can be used to retrieve useful real-world information from online services.

In conclusion, the Weather App (CLI) is a simple yet practical Python project that demonstrates the integration of programming concepts with real-time weather data retrieval. It provides a strong foundation for developing more advanced applications, such as weather forecasting systems with graphical user interfaces, five-day forecasts, and weather data visualization. Overall, this internship task was a valuable learning experience that improved programming skills and provided a better understanding of practical software development using Python.
